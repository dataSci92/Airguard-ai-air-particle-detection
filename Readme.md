# 🌿 AirGuard AI

### AI-Powered Air Particle & Pollution Detection System

AirGuard AI is an AI-assisted environmental monitoring prototype designed to analyze camera images for visible pollution indicators and present detection results through an interactive dashboard.

The system combines computer vision, machine learning, and data analytics to help visualize potential pollution events and support environmental monitoring workflows.

---

## 🚀 Features

- 📷 Camera/image-based pollution detection
- 🤖 AI-powered object detection using YOLO
- 🎯 Confidence-based detection filtering
- 📦 Bounding-box visualization
- 📊 Detection analytics and statistics
- 🌫️ Visual pollution severity indicator
- 📈 Average model confidence tracking
- 🧪 Optional PM1.0, PM2.5 and PM10 sensor integration
- 🖥️ Interactive Streamlit dashboard
- ⚡ Real-time-style detection workflow
